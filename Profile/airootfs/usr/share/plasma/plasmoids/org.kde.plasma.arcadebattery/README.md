# Arcade Battery Widget

A premium, highly-polished battery indicator plasmoid designed for ArcadeLinux KDE Plasma 6.

## Features

- **Pristine Aesthetics:** A sleek capsule design with true linear centering for perfectly balanced text, regardless of the charging state.
- **Dynamic Gradients:** Beautiful, energetic neon green gradients that dynamically sweep and fill when charging.
- **Micro-Animations:** Fluid, satisfying 800ms "loading sweep" and "bolt drop" animations that replay seamlessly whenever the widget is clicked.
- **Smart Thresholds:** 
  - Turns yellow at <= 30% and triggers a "Battery Low" desktop notification.
  - Turns critical red at exactly <= 10% and triggers an urgent, un-cancelable "Battery Critical" warning.
- **Custom Warning SVGs:** Features crisp, built-in custom SVG warning and critical error icons that appear dynamically when unplugged at low battery.
- **Live Rendered Notifications:** Desktop notifications capture a flawless, live snapshot of your exact custom QML pill battery to use as the notification icon.
- **Real-Time Bluetooth Tracking:** Polls your system's power state every 2 seconds, providing instantaneous updates and desktop notifications the moment wireless devices (headphones, mice) connect or disconnect.
